# RealWorld data variant v1

Serve the configured proposer's public RealWorld collection. Signed behavior
and variant publications identify the schema and expected proposer principal.
MySQL replicas restore its endorsed baseline and replay published binlogs.
Latest data means the latest asynchronously published state; replication lag is
expected. Read and mutation functionalities have separate identities.

Object identifiers refer to exact content. Storage is purchased for a duration;
interested parties may renew or revive content. Permanent availability is not
guaranteed. The object variant identifies the KvStore functionality used by the
collection. Browser CORS requests and preflights must be supported.
