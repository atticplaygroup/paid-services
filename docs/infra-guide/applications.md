# Applications

Infrastructure provider may provide applications themselves too. They are thin wrappers that translates business API to resource access. They are application workloads in traditional apps. They can be used to bridge existing applications.

Users using them will trust the infrastructure on the business logic of them. Trust is important. For example an OCI instance checks digest of CAS objects. If you do not trust, run your own application service or include the logic in your client, for example as a typescript library.
